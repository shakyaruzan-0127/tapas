Closures

closure allwos a function to access a variable from its outer scope even if the outer finished its execution

usefulness of closure
  • can keep variables private without exposing them
  • can stop variable pollution
  • can create a function factory
  • can keep a variable alive between multiple calls
When a closure references an object, that object stays in memory because the closure maintains a reference to it, preventing garbage collection until the closure itself is no longer reachable.
